# 🤖 AI Study Buddy

AI Study Buddy is a Streamlit-based smart learning assistant that helps students understand concepts through interactive AI explanations powered by Google Gemini.  
It enables question answering, concept breakdown, revision support, and chat-style learning — making studying smarter and easier.

---

## 🚀 Features

✔ AI-powered concept explanation  
✔ Chat-style question answering  
✔ Simple Streamlit UI  
✔ Gemini API integration  
✔ Modular clean architecture (components, utils, core)
